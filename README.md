# SAIS: Semantic Anchor & Intent Score

SAIS is a proprietary, reference-based metric for evaluating LLM-generated text. It combines
semantic equivalence, idea-order alignment, factual precision and recall,
explicit constraints, and a symmetric length penalty.

> **Research status:** This is an early research implementation. A score is not
> evidence of factual truth. Use it alongside human review for consequential
> decisions.

## Score

For candidate text $C$ and reference text $R$:

$$
\operatorname{SAIS}(C,R)=
[\alpha S_{\mathrm{mesh}}+(1-\alpha)S_{\mathrm{logic}}]
\cdot S_{\mathrm{fact}}\cdot\Gamma\cdot BP.
$$

All components are in $[0,1]$:

- **Meaning Mesh:** normalized embedding cosine similarity,
  $S_{\mathrm{mesh}}=(1+\cos(u,v))/2$.
- **Logic Flow:** each reference idea block aligns to its best candidate block,
  discounted by normalized positional distance.
- **Fact Anchor:** canonical fact matching with an $F_\beta$ score, so both
  omissions and unmatched candidate facts lower the result.
- **Constraint Gate:** product of explicit constraint factors, including hard
  failures with factor zero.
- **Brevity Penalty:** $BP=\exp[-\beta|\log(|C|/\max(|R|,1))|]$, which
  penalizes both unusually short and unusually long responses.

See [`docs/SAIS_preprint.tex`](docs/SAIS_preprint.tex) for the full design.

```bash
py -m pip install -e .[dev]

```

The first use of `SentenceTransformerEncoder` downloads the configured model
from Hugging Face. If that network connection is unavailable, pre-populate the
model cache or pass `HashingEncoder` for tests only. Do not use hashing-encoder
scores as scientific benchmark results.

## Quick start

```python
from sais_score import SAISScorer, Constraint

scorer = SAISScorer()  # lazily loads sentence-transformers on first score
result = scorer.score(
    candidate="The launch is scheduled for October 24, 2026.",
    reference="The launch is scheduled for 2026-10-24.",
    required_facts=["2026-10-24", "launch"],
    constraints=[Constraint.required("launch")],
)

print(result.score)
print(result.missing_facts, result.unmatched_candidate_facts)
```

Use a deterministic no-download encoder for tests and constrained environments:

```python
from sais_score import HashingEncoder, SAISScorer

result = SAISScorer(encoder=HashingEncoder()).score(
    "Water freezes at 0 degrees Celsius.",
    "Water freezes at 0 °C.",
)
```

To use the local Ollama embedding model:

```python
from sais_score import OllamaEncoder, SAISScorer

result = SAISScorer(
    encoder=OllamaEncoder("qwen3-embedding:0.6b")
).score("candidate text", "reference text")
```

## CLI

```bash
sais-score \
  --candidate "The event is on October 24, 2026." \
  --reference "The event is on 2026-10-24." \
  --fact 2026-10-24 \
  --encoder hashing
```

## Benchmarks

`benchmarks/evaluate_jsonl.py` evaluates SAIS and optional BLEU, ROUGE-L, and
BERTScore against a local JSONL file with `candidate`, `reference`, and
`human_score` fields. `benchmarks/evaluate_wmt.py` implements a WMT
system-level protocol through the official `mt-metrics-eval` toolkit. Both
report Pearson and Spearman correlations without claiming results until a
dataset is supplied and the command is run.
